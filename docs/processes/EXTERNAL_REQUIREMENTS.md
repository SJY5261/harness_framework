# 외부 요구사항 확보 절차

Jira 이슈·첨부 이미지·Figma·MCP 문서 등 저장소 밖 자료가 화면이나 기능 요구사항의 정본일 때만 적용한다.

## 구현 전 확인

1. 이슈 번호와 필요한 본문·첨부 이미지·최신 수정 시점을 확인한다.
2. MCP나 연결 도구로 정본을 직접 열어 구현 대상과 비교한다.
3. 로컬 사본을 사용할 때는 같은 이슈·버전의 자료임을 확인한다.
4. 화면 작업은 레이아웃, 문구, 노출 조건, 동작을 항목별로 추출하고 현재 코드와 대조한다.

## 자료를 확보하지 못했을 때

- handoff, 과거 구현, 파일명, 기억만으로 요구사항을 추정해 구현하지 않는다.
- 접근 실패 원인과 확보하지 못한 자료를 짧게 정리한다.
- 변경을 시작하거나 계속하지 않고 사용자에게 자료 제공 또는 대체 정본 승인을 요청한다.
- 사용자가 대체 자료를 정본으로 명시한 경우에만 그 범위에서 재개한다.

## 완료 전 확인

- [ ] 사용한 이슈·첨부·문서가 요청한 대상과 같은지 확인했다.
- [ ] 정본의 각 요구사항과 실제 diff를 일대일로 대조했다.
- [ ] 확보하지 못한 항목을 추정 구현하지 않았다.
- [ ] 시각 요구사항은 가능한 경우 실제 화면 또는 캡처로 비교했다.
