# 사용자 환경 지식

이 폴더는 일반론의 이론상 최적이 아니라 이 사용자의 실제 환경에서 효과적인 결정을 내리기 위한 정본이다. 제품 불변식은 `PROJECT_RULES.md`, 실행 규칙은 `AGENTS.md`, 작업별 상태는 `HANDOFF.md`와 `handoff/`가 계속 담당한다.

## 문서 지도

| 문서 | 읽는 조건 |
|---|---|
| [판단기준.md](판단기준.md) | 대안·최적화·위험·비용·품질 사이의 선택이 필요할 때 |
| [PC환경.md](PC환경.md) | 성능, 운영체제, 드라이브, 로컬 실행 가능성을 판단할 때 |
| [사용툴.md](사용툴.md) | 개발·검증 도구, 버전, 실행 경로, 설치 상태가 필요할 때 |
| [작업성향.md](작업성향.md) | 설명 방식, 자율성, 품질·비용 선호, 사용자 검토 단위를 정할 때 |

## 사용과 갱신

1. `AGENTS.md`의 환경 맞춤 원칙은 모든 작업에 적용한다.
2. 환경에 따라 결론이 달라질 때만 위 표에서 필요한 문서를 선택해 읽는다. 폴더 전체를 상시 로드하지 않는다.
3. 현재 시스템에서 확인 가능한 정보는 읽기 전용으로 다시 측정한다. 날짜가 있는 스냅샷을 영구 사실로 간주하지 않는다.
4. 작업 중 확인한 환경 사실이 이후 판단에도 유효하면 해당 문서만 갱신한다.
5. 시스템에서 확인할 수 없고 현재 결과를 실질적으로 바꾸는 정보만 사용자에게 묻는다. 단순 호기심이나 미래 가능성 때문에 질문하지 않는다.
6. 확인 상태는 `사용자 확정`, `시스템 확인`, `관찰`, `추론`, `재확인 필요`로 구분한다.

## 기록하지 않는 정보

- 비밀번호, API 키, 토큰, 쿠키, 인증 파일 원문
- DB 업무 데이터, 고객·직원 개인정보, 사내 비공개 원문
- 사용자 계정명, 호스트명, 장치 일련번호, MAC·IP 등 네트워크 식별자
- 원시 로그 전체와 재현에 필요하지 않은 개인 파일 목록

민감정보의 존재와 보관 위치가 작업에 필요하면 값 대신 “보안 저장소에 있음”처럼 상태만 기록한다.
