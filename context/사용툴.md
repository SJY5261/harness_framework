## Codex 운영 선호

- 사용량이 충분한 동안 토큰 절약만을 이유로 모델이나 추론 수준을 낮추지 않는다.
- 저장소 공용 규칙·훅은 `.codex/`, 개인 모델·권한·인증은 사용자 Codex 설정에서 관리한다.
- Claude는 사용자가 현재 프롬프트에서 명시했을 때만 Claude 세션에서 별도로 사용한다.
- Codex CLI의 사용자 `Path`와 새 셸 실행 정본은 `D:\Tool\nodejs`다. 실행 중인 기존 C: 세션이 모두 종료되면 로그인 자동 작업이 C: 중복 사본을 해시 재검증 후 삭제하며, 완료 여부는 `handoff/Codex주에이전트전환.md`와 실제 `Get-Command codex -All`로 재측정한다.

## 프로젝트 기술 스택

제품 기술과 버전 불변식은 이 문서에 복제하지 않고 `PROJECT_RULES.md`를 정본으로 사용한다. 구체적인 실행 경로는 `PATHS.md`, 테스트 명령은 `PROJECT_RULES.md`와 관련 handoff를 따른다.

## 갱신 기준

- 버전·설치 경로·기본 실행 명령이 바뀌었을 때
- 새 도구가 실제 반복 작업에 사용되기 시작했을 때
- 설치 여부가 아니라 현재 `Path`와 실제 실행 결과를 확인했을 때

설치 프로그램 목록 전체를 수집하지 않고 현재 개발·검증 흐름에 실제로 필요한 도구만 유지한다.
