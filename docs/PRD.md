# PRD: Tomes-Cloud

## 목표
제조업 고객사를 위한 클라우드 기반 ERP 백오피스 시스템.
주문·자재·공정·검사·견적·출고 등 제조 전 과정을 통합 관리한다.

## 사용자
- 제조업 고객사 내부 직원 (생산, 영업, 자재, 품질 담당자)
- 시스템 관리자 (기준코드·사용자 관리)
- 멀티테넌트: 도입 기업별로 독립된 데이터 환경

## 핵심 기능
1. 주문 관리 — 주문 생성·조회·수정·통계
2. 자재 관리 — 자재 마스터, 재고 관리
3. 공정·검사 — 작업 공정, 품질 검사
4. 견적·출고 — 견적서 생성, 출고 처리
5. 도면 관리 — 도면 파일 업로드·조회
6. 문서 출력 — PDF(JasperReports), Excel(POI) 생성
7. 바코드·라벨 — 바코드 생성, 프린터 연동
8. 실시간 알림 — WebSocket 기반 알림, 메일 발송
9. 기준코드 관리 — 도입 기업 공통 코드 통합 관리
10. 사용자 인증 — JWT, 파일 토큰 기반 인증

## 현재 진행 중인 작업
1. ParamQuery Grid 7.x → 11.0.0 마이그레이션 — 문법 변경으로 인한 편의 기능 오류 수정
2. 기준관리코드 통일 — 도입 기업별 코드를 공통 기준으로 통합, XML 쿼리 검증

## MVP 제외 사항
- 모바일 앱
- 외부 연동 API 신규 개발

## 디자인
- 관리자 도구 중심 UI (대시보드, 그리드, 폼)
- ParamQuery Grid 기반 데이터 테이블
